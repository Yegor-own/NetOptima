Полнофункциональный аппаратно-независимый веб-сервис для автоматизированного синтеза топологии опорных сетей связи, распределения пропускной способности и многопутевой маршрутизации трафика (задача **TCFA** — *Topology, Capacity, and Flow Assignment*). 

Сервис решает задачу смешанного целочисленного линейного программирования (**MILP**), минимизируя суммарные капитальные затраты (CAPEX) на физическую прокладку магистральных линий и аренду/установку пропускной емкости.

## 🚀 Функциональные возможности

- **Интерактивный картографический редактор:**
  - Добавление и геопозиционирование узлов сети (PoP / Базовые станции).
  - Управление множеством потенциальных (кандидатных) линий связи $\mathcal{E}$.
  - Возможность принудительной фиксации/запрета конкретных каналов пользователем.
- **Матрица требований (Demands Editor):**
  - Задание потоков трафика между узлами сети источниками и приемниками ($h_d$).
- **Аналитический MILP-солвер:**
  - Поиск оптимальной конфигурации сети с учетом геодезического расстояния между узлами (расчет через PostGIS).
  - Поддержка двунаправленных физических каналов и ориентированных потоков.
- **Визуализация результатов («What-If» анализ):**
  - Подсветка построенных линий связи ($z_e = 1$) с дифференциацией толщины по выделенной емкости $u_e$.
  - Отображение фактических путей прохождения трафика для каждого требования.
  - Оперативный перерасчет при изменении параметров удельной стоимости ($c_{km}, c_u, U$).

## 📐 Математическая постановка задачи

Задача формулируется как модель **Mixed-Integer Linear Programming (MILP)**:

### 1. Целевая функция (Минимизация совокупной стоимости сети):
$$\min \sum_{e \in \mathcal{E}} c_{km} \cdot d_e \cdot z_e + \sum_{e \in \mathcal{E}} c_u \cdot u_e$$

где:
- $z_e \in \{0, 1\}$ — факт физической прокладки канала $e$;
- $u_e \ge 0$ — выделенная пропускная способность канала $e$;
- $d_e$ — геодезическая длина канала (км);
- $c_{km}$ — стоимость прокладки 1 км линии;
- $c_u$ — стоимость единицы емкости канала.

### 2. Ключевые ограничения:
* **Контроль емкости физического канала:**
  $$u_e \le U \cdot z_e, \quad \forall e \in \mathcal{E}$$
* **Непревышение пропускной способности суммарным трафиком:**
  $$\sum_{d \in \mathcal{D}} x_{de} \le u_e, \quad \forall e \in \mathcal{E}$$
* **Закон сохранения потока в узлах (Flow Conservation):**
  $$\sum_{e \in \delta^+(n)} x_{de} - \sum_{e \in \delta^-(n)} x_{de} = \begin{cases} 
  h_d, & \text{если } n = a(d) \text{ (источник)} \\ 
  -h_d, & \text{если } n = b(d) \text{ (приемник)} \\ 
  0, & \text{в противном случае} 
  \end{cases} \quad \forall d \in \mathcal{D}, \forall n \in \mathcal{N}$$
